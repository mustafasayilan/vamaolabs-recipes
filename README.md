# VamaoLabs recipes

Practical, locally tested examples by Mustafa Sayilan, founder of [VamaoLabs](https://vamaolabs.com/about).

Each folder includes its own setup, tested versions, limitations, tests and LICENSE. Original independent scripts use MIT; platform-derived examples keep their GPL-compatible licenses and attribution. This repository contains no paid product source, license implementation or customer data. Tests run locally before publication; no GitHub Actions workflows are used.

Start with [WooCommerce CSV structure checks](woocommerce/csv-structure-check/README.md).
